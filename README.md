## 👩‍💻 Introduction

안녕하세요, 신입 풀스택 개발자 박소희입니다.

React·TypeScript로 프론트엔드를 만들고 Node.js·Supabase로 백엔드까지 직접 연결하는 작업을 좋아합니다. KDT 부트캠프에서 4인 팀 프로젝트를 3회 진행하며 웹 쇼핑몰, 3D 인터랙티브 게임, Unity 연동 크로스플랫폼 게임까지 **기획 → 설계 → 구현 → 배포**의 전 과정을 경험했고, 그 외에도 캘린더·독서 관리 앱 등 개인 프로젝트로 아이디어를 직접 서비스로 만들어보고 있습니다.

- 🔭 최근에는 React/TypeScript 기반 서비스에 Supabase(BaaS)를 연동해 별도 백엔드 구축 없이 인증·DB·결제까지 처리하는 구조에 관심을 두고 있습니다.
- 🌱 팀 프로젝트마다 UI 구현과 화면 간 데이터 흐름 설계를 주로 맡아왔고, 3D/게임 요소(Three.js, Unity)를 웹과 연동하는 작업도 경험했습니다.
- 📫 협업 경험 : 대학 영상편집 동아리 INOSIF 회장, 필리핀·베트남 해외봉사(WFK PAS)
